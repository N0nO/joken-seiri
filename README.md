# 条件整理・無料2題

GitHub Pages用の公開フォルダです。`index.html` と同じ階層にある全ファイルを、公開リポジトリのルートへ置いてください。

## GitHubでの公開手順

1. GitHubで公開リポジトリ `joken-seiri` を作成します。
2. このフォルダ内のファイルを、リポジトリのルートへアップロードします。
3. リポジトリの **Settings → Pages** を開き、`Deploy from a branch` を選びます。
4. Branchを `main`、フォルダを `/(root)` にして保存します。
5. 公開URLは通常 `https://n0no.github.io/joken-seiri/` です。表示された実際のURLを確認してから、Xとnoteのリンクを差し替えてください。

このフォルダは無料2題だけです。有料20題、購入者向けZIP、運営ページは含みません。
